# IG 圖文

每篇固定 4 張圖文加 Caption。敘事依 [共用框架](../.agents/skills/market-video-story/references/story-framework.md)，文字格式依 [輸出約定](../.agents/skills/weekly-market-writing/references/output-schemas.md#ig-圖文稿)。

## 範本

- `template-2026-11-09-published.docx`：現行版型，即 2026-11-09 已發布的《老黃認了出軌！NVIDIA董事會啟動調查》Google Doc。新貼文從這份套版，保留字體、字級、行距與分頁。`template-2026-11-09-assets/` 是它的內嵌圖與 5 頁預覽。
- `格式範本-2026-11-05-AI暫停.md`：Markdown 文字源的格式範例。
- `格式範本-原始.docx`：較早的原始版型，2026-11-08 那篇由它套版。
- `製作工具/build-ig-docx-2026-11-12.py`：從 Markdown 填入現行版型產 DOCX 的腳本。段落索引對應現行版型，路徑寫死為當時的工作目錄，重用前先改路徑。

## 配圖

- 官方頭像、官網截圖可直接使用，另存於當篇 `refs/`。新聞照片只當參考，用 AI 再製，不把原圖貼進貼文。
- 依公開照片 AI 再製或 AI 示意圖時，配圖說明逐張寫明性質；圖面本身不加浮水印或文字。
- 沒有公開合照，就不生成親密或偷拍感的畫面。圖片尺寸 4:5。
