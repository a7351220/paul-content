# 保羅內容

市場週報與主題影片的逐字稿、研究資料、視覺素材、簡報，以及製作流程 skills。

## 目錄

- [週報](週報/)：依日期整理的市場週報。
- [主題影片](主題影片/)：個別題目的研究、逐字稿與製作檔案。
- [共用素材](共用素材/)：範本、視覺格式與管理紀錄。
- [參考研究](參考研究/)：跨題參考資料。
- [Skills](.agents/skills/)：路由、研究、寫作與製作交付四個 skills；敘事規則統一放在 [共用框架](.agents/skills/market-video-story/references/story-framework.md)。

各專案的歷史稿放在「歷史版本」，正式稿、素材和輸出分開保存。研究文件、樣稿及製作紀錄具有各自的資料日期，不作為即時行情。

## 取得完整檔案

圖片、簡報及其他大型二進位素材使用 Git LFS。安裝 Git LFS 後複製此儲存庫，並執行 `git lfs pull` 取得完整素材。

下載網頁中的網站 API key 已遮蔽；本機套件連結、系統暫存及環境設定檔不納入版本控制。第三方資料、圖表及品牌的權利歸原權利人，原始來源依專案內研究紀錄查閱。
