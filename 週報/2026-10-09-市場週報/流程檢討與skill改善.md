# 這次週報製作流程檢討

本次採用版本：22 頁固定格式重製版。使用者已確認視覺可用；這次只更新製作 skill 與流程紀錄，不再操作或檢查 Canva。

## 問題與改善

| 本次問題 | 原因 | 下次做法 |
|---|---|---|
| 先做出文字堆疊、重複線圖的投影片 | 沒把口白轉成各頁的視覺關係 | 每頁先定觀察、物件、比較或連接關係、必要數字，再選構圖 |
| 加插畫後又改成寫實場景 | 把「畫面感」當成攝影風格 | 先看固定參考 PNG，以工程等角插畫構成完整畫面 |
| 少字變成只剩「記憶體」或幾乎無字 | 混淆外部標題與主圖標籤 | 完整外部標題保留；主圖只放必要短字、數字與單位 |
| 主圖像插畫加上後貼文字 | 文字與插畫分開設計 | 主圖短字和插畫共同構圖；精確圖表預留區域再本地合成 |
| 第一頁開場被重寫 | 把範本固定宣傳段誤當舊示例 | 固定開場逐字保留在備註；大綱畫面只更新本集主題 |
| 備註修改有覆蓋新稿的風險 | 本地稿與 Canva 人工編輯並存 | 修改前保存最新 Canva 備註，保留人工修改，合併指定修正 |
| 小修正仍持續做全套檢查 | 沒有依修改範圍與使用者確認收斂 | 初交付核對全套；局部修改只核對相關頁；使用者說可以就停 |

## 下次流程

1. 分開確認「多題週報／單題影片」與「視覺版型」。週報選主題影片版型，仍有大綱與完整分類標題。
2. 讀範本及實際參考圖，沿用固定開場；研究與價格資料依本期更新。
3. 把每頁口白變成明確畫面：外部標題、主圖短字與數據、物件及關係、真實資料圖位置、對應參考圖。
4. 按已確認固定格式生成主圖，依內容交替使用比較、服務關係、大數字和精確圖表。沒有灰色圖片來源註腳，來源留在研究文件。
5. 本地套版並寫入完整備註；保留原生圖表。若 Canva 匯入失真，再以完整頁面圖片匯入並保留可編輯備註。
6. 完成一次交付核對後收尾。後續修正沿用正式 Canva 連結，保留使用者人工編輯，不重建全套。
