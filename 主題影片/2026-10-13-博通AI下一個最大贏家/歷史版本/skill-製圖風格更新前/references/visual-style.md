# 保羅市場影片固定視覺格式

設計依據：`2026-10-02 市場週報｜乾淨統一重建版.pptx`。已檢視其中 19 張內容主圖、品牌背景與主題分類標題，保留原檔。

## 先讀圖，再定構圖

先實際查看參考 PNG；不能只讀配色文字就開始整批生成。原始參考 03、07、17 用來校準風格，下列是 2026-10-10 使用者確認「這次的視覺還不錯」的修正版例子：

- [競爭比較主圖](style-examples/已確認-競爭比較主圖.png)：用兩個供應商與大數字形成同一幅工程插畫。
- [服務關係主圖](style-examples/已確認-服務關係主圖.png)：具體物件、短標籤與連接關係共同構圖。
- [真實圖表整頁](style-examples/已確認-真實圖表整頁.png)、[資金流圖表整頁](style-examples/已確認-資金流圖表整頁.png)：展示精確資料圖與外部標題、品牌的位置。這兩張是整頁例子，不要再縮進主圖框。

例子的市場數字只供理解構圖，不作新一期研究。使用者有新參考時以新參考優先。

「畫面感、有場景」在這套風格中，指物件、數字、比較及連接共同表達一件事；不代表切換成攝影棚、街景、寫實人物或照片背景。單獨丟一個插圖再配幾個字，仍未完成構圖。

## 整頁與內容主圖

整頁維持 16:9 白底，左下貓頭鷹使用原圖。右側放內容主圖。品牌、外部標題和內容主圖分開處理，避免每次生成都改變貓頭鷹或標題位置。

本次參考 PPT 尺寸為 20 × 11.25 英吋。一般內容頁的主圖約位於整頁左側 20.8%、上方 11.7%，寬約 77.1%、高約 76.5%。這是參考檔的版面讀取值；套版時沿用實際範本物件與位置。

- 週報：每個主題一個完整分類標題，同題各頁共用；另有開場大綱。外部標題不受主圖少字原則限制，不能縮成「記憶體」等單字，也不能因改用主題影片視覺版型而移除。
- 主題片：只有第一頁的大標題。後續不加頁首標題；年份、數值、圖例、流程節點與短註解可以留在主圖。
- 生成交付以右側內容主圖為單位，一頁一張。建議 1920 × 1080 或更高的 16:9 PNG；不要把左側品牌空間再畫進主圖。
- 重要資訊距主圖邊緣至少約 5%，避免套版或縮放後貼邊。

## 真實數據與圖表

使用者允許把真實價格、研究曲線與數據圖依固定風格重繪，呈現像閱讀網站資料截圖的感覺。先取得真實來源，再保留原數值、期間、單位、軸尺度、圖例與資料日期；完成後逐一核對。無法確認曲線重繪準確時，使用原始研究圖，周圍套用固定版式與重點註解。不得用生成模型臆造資料走勢，或添加假網站介面、官方標記讓人誤認來源。

有原始數據時，以本地繪圖工具重繪精確圖表；只有研究圖片且無法可靠復原曲線時，直接保留真實圖表區域，周圍配上米白背景、深藍／磚橘註解。AI 生圖即使拿到原圖，仍可能改變峰值、年份、雙軸或曲線，不能只因看起來相似就當成真實數據。對數軸與雙軸需保留標示；比較長條需核對比例。箭頭也有論點含義，例如穩定幣供給增加不能畫成全部流向 BTC。

## 固定外觀

| 元素 | 固定規則 |
|---|---|
| 主圖底色 | 米白、淡紙感；整頁外側仍為白底 |
| 文字與輪廓 | 深海軍藍，接近 `#0C1B2F` |
| 重點色 | 磚橘，接近 `#B75A38`；用在重點數字、少量色塊或資金方向 |
| 輔助色 | 淡灰線與冷灰側面，接近 `#CFD0CC`、`#929BA4` |
| 背景 | 低對比方格、施工線或尺寸輔助線，局部使用，不搶內容 |
| 字體觀感 | 繁中粗黑體；數字粗、窄、醒目；不使用書法字或細字當主訊息 |
| 插圖 | 工程製圖感、深藍清楚描邊、等角視角、平面色塊、少量灰色投影 |
| 構圖 | 一個主要視覺，搭配少量數字或短標籤；用留白建立層次 |
| 品牌 | 貓頭鷹沿用原圖，禁止重新生成；公司標誌需要時使用正式素材 |

色碼是依參考畫面整理的近似製作色，不是原圖可編輯色票。AI 生成可維持這套風格，但字形與細節仍可能有變化；需要每次完全一致的文字、數字與品牌元素，應在本地用固定文字物件與原圖完成。

## 文字層次與整體畫面

- 外部主題標題：保留完整題意，由本地範本排版。
- 主圖：少量關鍵字、公司名、數字、年份與必要單位；與插畫一起安排大小、位置及視覺關係。預設生成時就把指定短字與畫面一起完成。不能放整段口白，也不能為了少字刪到無法辨識比較對象。
- 圖表：保留軸、圖例、期間及單位。圖表資料用本地繪圖或真實來源，先規劃生成背景的保留區再合成，不讓模型畫走勢。
- 圖片下方不加灰色「圖片來源」說明行。來源保存在研究文件；真實圖表的必要讀圖資訊不能一併刪掉。

生成前，每頁先定義：本頁觀察、完整外部標題、主圖必留短字與數字、具體視覺物件、物件間關係、資料圖位置（若有）、最接近的參考圖。由論點選構圖，避免整片都用同款折線、箭頭、卡片或孤立圖示。若需要生成試版，可選有代表性的比較頁、概念頁和真實資料頁；整批已獲授權時，不另設強制批准關卡。

## 四種常用構圖

1. **大數字搭插圖**：數字約占主圖三分之一至二分之一；旁邊一個工程線稿物件。參考主圖 02、12、15。
2. **左右比較**：兩側對齊、相同資訊層級，中間簡單分隔。參考主圖 03、08、17。
3. **資金或操作流程**：兩至四個具體物件，以清楚管線或箭頭連接。參考主圖 07、11、16、19。
4. **原始圖表與數字註解**：保留來源圖表的軸、期間與圖例，周圍套用相同色調和字體。原始資料不改成憑空生成的走勢。

每頁依內容選構圖，不把同一張比特幣硬幣重複當全片背景。參考檔中不相關的舊產品標誌、舊數據、細碎假文件文字與平台標記，不納入固定格式。

## 通用生成描述

使用者要求試版時，先完成指定張數並等回饋；確認風格且授權整批後，沿用已確認試版與參考圖完成其餘頁，不重開同一個批准步驟。每頁按本頁資訊選構圖，品牌由本地範本加回。

下列段落搭配各頁的構圖、精確文字與限制使用。生成時同時提供 `style-examples/參考-03.png`、`style-examples/參考-07.png` 或 `style-examples/參考-17.png`，選擇與該頁構圖最接近的參考。

> 生成一張 16:9 投資影片內容主圖。視覺跟提供的保羅週報參考一致：米白紙感底、深海軍藍粗黑體與清楚輪廓、少量磚橘色重點、淡灰工程格線、等角工程插圖、少量灰色投影。畫面乾淨，一個主要意思，文字短而大，留白充足。只生成右側內容主圖，不生成外層 PPT、貓頭鷹或額外頁首標題。指定短字、大數字與插畫一併構圖，讓畫面有清楚的比較或服務關係，避免孤立圖示排排站。文字全部使用指定的繁體中文、英文、日期與數字；不加整段說明、重複主題標題或灰色來源註腳。不要添加未指定的數據、來源截圖、金融文件、價格曲線、裝飾標誌或平台標記。只模仿參考的視覺風格，內容依本頁指定。

## 資料與生成的分工

- 概念頁與工程插圖：可以直接依參考生成。
- 數值比較頁：數字依已確認研究；圖形比例、單位與日期必須核對。需精確比例或可編輯時，用本地原生圖表完成。
- 新聞、公告、研究曲線：使用真實來源圖，保留必要標示，再放入固定版面；AI 不生成假截圖。
- 主圖短字：預設與插畫一起生成；若生成字形出錯，優先修正該主圖，不把後貼的大段文字當成補救。
- 必須固定字型或可編輯的字：在本地完成，從構圖階段就安排進畫面；文字較多先縮減成關鍵訊息。整張已含字 PNG 的文字不能像 PPT 文字物件一樣單獨修改。

## 交付核對

逐張檢查：對應當頁口白、繁中字形、數字、日期、分母、比較方式、流程方向、內容是否超出證據、縮小後是否能讀。全部採同一套色調與線稿風格，仍依各頁內容變換主視覺。

內容主圖完成後，在本地範本放入圖片與逐頁完整講者備註；匯入 Canva 後再讀回圖片順序和備註。
