## 主問題與子問題

比特幣目前的簽章會不會被足夠強大的量子電腦破解，而比特幣有沒有時間與能力完成遷移？

1. 兩則使用者貼文各自引用什麼，哪些是研究、哪些是市場人物的意見？
2. 公鑰與私鑰可以怎麼用鎖與鑰匙說明，量子攻擊又改變哪一件事？
3. Anthropic 的新結果改進了哪個運算環節，能否換算成完整破解速度？
4. 論文下修了哪些硬體或運算需求，數字比較的對象是什麼？
5. 哪些幣的公鑰長期曝光，哪些只有花費時曝光？
6. 機構對風險與時間表有何分歧，估計的範圍是否相同？
7. 升級能保護誰，遺失私鑰、沉睡幣與網路共識留下什麼難題？

## 概念順序

新研究讓風險可能加快 → 有多少幣需要保護 → 防護工具已存在 → 容量、錢包與協調讓升級需要時間 → 持有人與業者遷移 → 遺失私鑰的老幣造成共識難題 → 影響全體持有人。

核定開場 → 鎖與鑰匙 → 量子回推私鑰 → Google硬體估計 → Anthropic設計與改進 → 公開公鑰的資產規模 → NIST抗量子簽章 → BIP360地址草案 → 容量與錢包使用代價 → 測試和共識 → Google升級目標與準備時間 → 自託管／業者轉移 → 私鑰遺失老幣 → BIP361與權利爭議 → 市場影響 → 回答原問題。
