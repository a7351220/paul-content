# 市場影片寫作與口播修訂

負責週報、主題片與 IG 圖文的大綱、逐字稿與修訂。寫前讀[共用敘事框架](../market-video-story/references/story-framework.md)，按[輸出約定](references/output-schemas.md)交付；不另設一套口播規則。

沿用最新人工稿與已有研究，只完成當次要求的範圍。需要補證據時找[研究 skill](../weekly-market-research/SKILL.md)；涉及數字或指定篇幅時讀[核算方式](../market-video-story/references/data-and-length.md)。

稿源與修改邊界依[內容流程](../weekly-market-pipeline/SKILL.md)。Canva 或 Google Doc 有人工改動時先讀回；需要同步畫面或交付物才接[製作 skill](../market-video-story/SKILL.md)，回報實際完成的範圍。

完成與版本同步依工作區 [AGENTS.md](../../../AGENTS.md)。
