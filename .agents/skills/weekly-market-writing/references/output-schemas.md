# 文字產物格式

只交當次要求的產物；沿用最新人工格式，沒有指定時使用以下約定。

| 產物 | 格式 |
|---|---|
| 敘事走向 | 說明背景、主線及線索關係，尚不分頁 |
| 大綱 | `Slide N｜主題標題`，配內容說明及材料對應 |
| 逐字稿 | 全片題目、頁碼與完整口白；主題片不用每頁重列題目 |
| Canva 講者備註 | 只有口白，不含頁碼、來源或製作註記 |
| Google Doc 口白匯出 | 依 Canva 當下頁序，以「第 N 頁」導航，保留原文 |

週報另列題目與頁碼範圍，同題使用相同完整標題，第一頁為本日／本週大綱。人工使用「第 N 頁」時直接沿用。頁數按指定值或內容需要，不設固定下限。

需要固定開場時取自 [weekly-opening.txt](../../market-video-story/assets/weekly-opening.txt)，採用最新確認的自介、發布口播及 CTA；人工已刪內容不補回。

來源與研究註記另存；必要歸屬仍保留在口白。敘事依[共用框架](../../market-video-story/references/story-framework.md)，線上操作與讀回依[交付規則](../../market-video-story/SKILL.md)。
