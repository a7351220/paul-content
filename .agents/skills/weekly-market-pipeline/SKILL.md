# 週報流程路由

本 skill 只選擇入口及安排交接；敘事規則只讀 [共用框架](../market-video-story/references/story-framework.md)。

| 目前需求 | 負責 skill |
|---|---|
| 找題、研究、查證、更新行情或來源數據 | [weekly-market-research](../weekly-market-research/SKILL.md) |
| 背景與主題關係、大綱、逐字稿、全文口播修訂 | [weekly-market-writing](../weekly-market-writing/SKILL.md) |
| 原圖擷取、視覺建議、製圖、套版、Canva、文件匯出與版本同步 | [market-video-story](../market-video-story/SKILL.md) |

從現有進度接續，完整任務按研究 → 寫作 → 製作前進；只做當次授權的輸出，不逐階段重問批准。專責 skill 直接完成自己的工作，不再轉回本入口重新分派。

寫作或製作發現缺口時，記錄具體主張／數字、來源與期間、需要的資料；只請負責階段補件，取得結果後回到原任務。補件不重新選題、重建敘事或重跑已完成階段。同一缺口未解時回報缺少什麼，其餘工作繼續，不反覆交接。

交接沿用同一份最新材料：日期與研究截止、正式稿位置、最新人工修訂、核定頁數／順序／標題、來源與比較口徑、實際缺口及當前交付狀態。內部欄位不足不構成重做理由。

完成與版本同步依工作區 [AGENTS.md](../../../AGENTS.md)。
