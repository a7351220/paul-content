# 市場內容流程

先確認本次要做什麼、目前哪份是正式稿，直接接續已有進度。使用者已指定題目或授權交付，就繼續完成，不逐頁或逐階段重設批准關卡。

## 按工作選入口

| 工作 | 負責 skill |
|---|---|
| 找題、補來源、查核事實與數字 | [研究](../weekly-market-research/SKILL.md) |
| 大綱、逐字稿、敘事與口播修訂 | [寫作](../weekly-market-writing/SKILL.md) |
| 圖像、簡報、Canva、文件匯出與版本同步 | [製作](../market-video-story/SKILL.md) |

敘事原則只依[共用框架](../market-video-story/references/story-framework.md)，文字格式只依[輸出約定](../weekly-market-writing/references/output-schemas.md)。缺什麼就補什麼，不因局部修改重跑整個流程。

## 稿源與交付

以最新人工稿為準。Canva 或 Google Doc 已有人修改時，先讀回再操作，不用本地舊稿覆蓋；修改只擴及必要銜接和受影響交付物。來源與查證另存，正式口白保持乾淨。

在同集既有紀錄留下正式稿位置、線上連結、已同步與未同步項目，以及明確認可的回饋即可，不另建平行記憶庫，也不將私人資料寫入公開紀錄。

完成後核對實際內容與保存狀態，清楚回報交付範圍；GitHub 同步依 [AGENTS.md](../../../AGENTS.md)。
