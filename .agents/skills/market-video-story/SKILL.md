# 保羅市場影片製作與交付

本 skill 直接負責來源圖、視覺建議、製圖、套版及同步。敘事只讀 [共用框架](references/story-framework.md)，文字產物格式只讀 [寫作格式](../weekly-market-writing/references/output-schemas.md)。若任務尚在找題或寫稿，依 [流程路由](../weekly-market-pipeline/SKILL.md) 選對入口，不在此維護另一套寫作規則。

## 開始與專責參考

先確認當次輸出、最新人工修訂及正式專案；接續已完成階段，只做已授權工作。製圖前確認正式稿已包含採用的修訂。共用規則依下列位置讀取，不在此複寫：

- 畫風、原圖保存、生成圖邊界及視覺建議：[視覺規則](references/visual-style.md)。
- 版型、字體、套版、版本對照與 PPTX／Canva 修改：[本地組裝](references/local-assembly.md)。
- 行情比較與指定篇幅核算：[數據與篇幅核算](references/data-and-length.md)。
- 必要時校準既有聲音：[週報樣稿](references/weekly-example.txt)、[主題片認可稿](references/topic-example-quantum-final.txt)；僅學口吻及密度，不沿用歷史事實或頁數。

缺研究證據或需改口白時，按路由補件；製作本身不重選題、不自行重寫敘事。已有認可風格且獲授權整批就完成全套，不重新設批准關卡。

## Canva 人工稿與文件匯出

使用者已在 Canva 修稿時，修改或匯出前讀取全部現存備註與頁序並存快照。以穩定頁面 ID 對應內容，以目前頁碼輸出；人工刪頁、移頁及用字優先，不能用本地舊稿恢復已刪內容。這項讀取可供寫作取得輸入，不代表授權改動 Canva。

匯出 Google Doc 使用 Google Docs skill 建原生文件，依當下頁序保留原文，用「第 N 頁」作導航；不潤稿、不加來源或製作資訊。完成後讀回核對頁序和內容再提供連結。匯出不改 Canva，也不自動公開分享。

## 完成邊界

依要求交本地檔案、線上設計或文件；本地成功不能當作線上完成。首次交付檢查必要的頁序、素材、備註與實際版面；局部修改只查受影響項目，沒有新差異就停止。使用者要求停止檢查時立即停止額外操作。回報實際保存及同步的範圍，未更新的交付物須明列。

完成與版本同步依工作區 [AGENTS.md](../../../AGENTS.md)。
