# 本地套版與 Canva

## 範本與輸入

使用 [template.pptx](../assets/template.pptx)，當次新範本優先；在副本上操作。預設兩頁 16:9：第一頁週報大綱及 [固定開場](../assets/weekly-opening.txt)，第二頁內容主圖、上方標題及左下品牌。替換舊素材和備註佔位，保留原範本。

先查看實際範本及最新認可成品，重用大綱與標題的原生文字物件，連同字體、字級、段落、行距和位置；不重打相似文字框。現有認可週報使用「可画榜书」，實作仍以當次選定範本為準；整頁圖片只能參考外觀，不能證明原生字體。

貓頭鷹必須重用完整原始物件，包括位置、尺寸、裁切及填滿方式；不能抽出 PNG 再用 contain 重放。範本圖片可能是 `p:sp` 的 `a:blipFill`，不只 `p:pic`；按位置與關聯辨識，不全域換共享資產。

內容頁定位參考，實作讀取實際範本：

| 區域 | x | y | 寬 | 高 |
|---|---:|---:|---:|---:|
| 右側主圖 | 3804729 | 1208274 | 14101225 | 7870451 |
| 上方標題 | 3804761 | 266700 | 14097000 | 1047750 |
| 貓頭鷹 | 1091566 | 6463917 | 2994728 | 2794383 |

單位 EMU；範本尺寸 18288000 × 10287000。按素材比例適配，不裁掉必要標籤。

先找最新稿及最新人工修改，建立 Slide → 素材 → 口白對照。確認素材是右側主圖或整頁；頁數、順序有無法判定的差異時列出，不猜著貼或重複補頁。PDF 按原順序轉圖，保留來源。

## 組裝

使用簡報技能及當下可用工具。右側主圖依原區域放置；已套版整頁直接沿用，避免縮成雙重品牌。

- 頁序、第一頁、同題標題與備註內容依 [文字產物格式](../../weekly-market-writing/references/output-schemas.md) 實作；大綱及外層標題保留原生可編輯物件，不額外插封面。
- 外部標題依範本排版，優先可編輯文字；原標題可能是圖片，必須替換原物件。主圖已含相同標題時避免重複。
- 備註內容依文字產物格式逐頁寫入，不把逐字稿疊到畫面。

只改備註時，優先局部修改現有 PPTX 套件，保留圖表、媒體、嵌入工作簿及關聯；不要為了補備註重建全檔或憑空補造丟失的工作簿。

## 匯入及正式版本

本地完成後匯入 Canva，不重新套品牌模板。先讀當下工具參數；支援本地 `design_file` 時傳絕對路徑，否則用官方上傳，不能為匯入公開私人檔案。上傳資產不等於已建立設計。

首次交付核對本地頁數、素材順序、備註及渲染畫面，再讀回 Canva 對應頁面與備註；字型、裁切及品牌大小都可能在匯入時改變。備註未保留時用可用 API 或瀏覽器補上；無法完成就交代限制並交付本地 PPTX，不宣稱 Canva 已完成。

字體必須在 Canva 選取大綱及內容標題，查看工具列的實際字體並對照外觀；PPTX 字體名稱及本地渲染都不是匯入成功證據。若被替換（例如「可画榜书」變 Arimo），在同一設計選回原字體；只有該替代字體全都對應同一原字體時，才用「全部變更／所有頁面」，否則分物件修正。確認已套用及儲存，保留原連結，不為字體問題重建整套。

匯入失真先修正原生物件。只有不需要編輯的頁面才可改用本地完整渲染頁，逐頁保留口白備註；不能為掩蓋字體替換，把原本可編輯的大綱與範本文字壓成圖片。整頁圖不再縮進右側主圖框，並說明文字與圖片合一。

專案記錄一個正式 design ID、連結、最新檔案及備註同步狀態，歷史版另外保存，不堆多個「定稿」連結。只在建立、儲存及必要讀回成功後稱為完成；未經授權不刪舊設計。

## 修改既有交付

先保存並合併 Canva／聊天中較新的人工修改，候選句不能冒充已套用稿。按指定範圍同步本地稿、交付 PPTX 與正式 Canva：

- **只改口白**：保留原畫面和連結，只改對應備註。沒有備註 API 才用編輯器；虛擬縮圖可能跳錯頁，優先「前往頁面」並核對備註面板頁碼，實際 UI 優先。
- **一般修圖**：在原設計換指定頁；全頁圖替換整張套版頁。全套重製可另建設計，但更新唯一正式連結。
- **只改字體／版面**：在原設計修正文字物件，只核對受影響字體與排版，不重生主圖、不重查行情、不另匯入新設計。
- **暫存／中斷**：交易草稿不是儲存。記錄必要頁碼及資產 ID；恢復時先讀正式狀態，只補未儲存部分。縮圖快取用新預覽判斷，不重複上傳。

完成與停止條件依 [製作入口](../SKILL.md#完成邊界)，不另加重複檢查。

## 正式專案與版本對照

工作區使用既有分類：週報放 `週報/YYYY-MM-DD-市場週報/`，主題片放 `主題影片/YYYY-MM-DD-題目/`，範本與通用視覺放 `共用素材/`，跨題研究放 `參考研究/`。新稿件寫入對應專案，不散放工作區主目錄，也不另建 `reports/`。既有專案以當下實際位置為準。

維護一份精簡對照：穩定頁面 ID、當前頁序／標題、口白、素材、來源定位，以及正式 Canva／文件連結與各項同步狀態。頁序改變不改穩定 ID；新稿或人工編輯優先於舊對照。

增頁、刪頁或重排後先更新對照，再核對受影響稿件、備註及素材索引。只同步當次要求的交付物；其他版本記為待同步或歷史版，不能都稱最新。替換的稿件及素材移至同一專案歷史區，不混入使用中素材。Google Doc 匯出或同步依製作入口，無需維護另一套腳本 schema。
